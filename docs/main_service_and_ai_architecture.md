> **최근 수정일**: 2026-10-03

본 문서는 WanderMap의 핵심 서비스인 **여행 동선 생성 및 실시간 조율 시스템**, **ChatGPT/Gemini 스타일의 대화형 메인 홈 및 상세 페이지 3단 UI/UX**, 그리고 **Google Search Grounding 기반의 정확도 최우선 Gemini AI 연동 규격**을 상세히 정의합니다.

## 📌 1. 메인 서비스 핵심 개념 및 동선 기획 로직

### 1.1 일자별 여행 동선 설계
사용자가 특정 목적지(예: 일본 오사카, 제주도 등)를 정하고 여행을 계획할 때, WanderMap은 일자별(Day 1, Day 2...)로 현실적이고 유기적인 동선을 구성합니다:

* **Day 1 (도착 및 정착)**:
  - 공항/기차역 도착 ➔ 첫 식사(맛집) ➔ 숙소 체크인 및 짐 보관 ➔ 주변 번화가/야경 산책
* **Day 2 (핵심 관광 및 핫플레이스)**:
  - 기상 및 모닝 카페 ➔ 메인 관광지/문화 명소 ➔ 점심 맛집 ➔ 대중교통으로 연결되는 인기 관광지 또는 근교(예: 오사카 시내에서 나라 사슴공원, 교토 청수사 등) ➔ 디너 ➔ 숙소
* **Day 3 이후**:
  - 멤버들의 선호도와 피로도를 고려한 유동적 동선 및 귀국/체크아웃 연계

### 1.2 AI 추천의 역할과 고도화 지향점
1. **지능적인 지역 확장 및 권역 분석**:
   - 사용자가 단순히 "오사카"라고만 적어도, AI는 오사카 시내 중심(난바, 우메다)뿐만 아니라 간사이 권역(나라 사슴공원, 고베, 교토 등)의 근교 연계 동선까지 지능적으로 추천합니다.
2. **동선 추천의 2가지 진입 경로 (Dual Trigger)**:
   - **경로 A (원클릭 자동 추천 버튼)**: 목적지와 기간을 바탕으로 최적 템플릿 즉시 생성
   - **경로 B (Gemini식 확장형 프롬프트 바)**: *"첫날 난바 숙소 체크인하고 도톤보리 야경 위주로, 둘째 날은 나라 사슴공원 꼭 가고 싶어"*와 같은 세부 요구사항을 전달하여 맞춤 생성
3. **추천 결과 스마트 반영 (3가지 옵션)**:
   - **[전체 반영]**: 기존 일정을 AI 추천 결과로 일괄 덮어쓰기
   - **[부분 반영]**: 추천된 장소 카드 중 원하는 장소만 체크박스로 콕 집어서 내 동선에 삽입
   - **[수정 후 반영]**: 장소 순서나 시간, 메모를 사용자가 다듬은 후 동선에 확정

## 🔍 2. Gemini Grounding: 최신성 + 정확도 최우선 원칙

사용자의 제1원칙: **"무엇보다 정확한 정보가 제일 우선사항. Google 검색과 지도 도구를 통해 최신+정확한 정보를 받아야 함."**

### 2.1 Google Search Grounding 원칙
* Gemini API 호출 시 `tools: [{ google_search: {} }]`를 필수 활성화합니다.
* **실시간 검증**: 장소의 현재 영업 여부, 폐업 여부, 최신 핫플레이스 트렌드, 정확한 현지 주소를 Google 실시간 검색을 통해 크로스체크하여 환각(Hallucination)을 원천 차단합니다.

### 2.2 두 가지 AI 엔드포인트 및 JSON 응답 스키마 분리

AI 연동은 사용자 진입 지점에 따라 **신규 생성(홈 화면)**과 **동선 보완(상세 페이지)** 2개의 별도 엔드포인트로 운영됩니다. 특히 **상세 페이지에서는 사용자가 정한 기존 여행 제목(`title`)이 유지되어야 하므로 응답에 `title`이 포함되지 않으며, 기존 제목을 절대로 덮어쓰지 않습니다.**

#### 2.2.2 [API 2] 상세 페이지 동선 보완/재추천 (`POST /api/ai/trips/{tripId}/recommend`)
* **목적**: 이미 생성된 여행 방 안에서 추가 장소 추천, 특정 일자 코스 수정 등 세부 동선 조율
* **핵심 원칙**: 
  1. **`title` 필드 제외**: 상세 페이지에서는 이미 사용자가 정해둔 소중한 여행 방 제목(예: *"우당탕탕 3인 오사카 먹방", "지수와 함께하는 졸업여행"*)이 존재하므로, **AI 응답에 `title`이 올 필요가 없으며 응답 스키마에서 제외**됩니다.

### 2.3 날짜 미지정 시의 안전한 처리 규칙
- 사용자가 프롬프트나 입력란에 구체적인 날짜를 적지 않았다면, **임의의 가짜 날짜를 채우지 않고 `startDate: null`, `endDate: null`로 안전하게 반환**합니다.
- 대신 "3박 4일", "2박 3일" 등 기간 언급에 따라 `Day 1`, `Day 2`... 상대 일정 번호로 구조화하여 상세 페이지에서도 깔끔하게 미정 날짜로 표시됩니다.

## 🎨 3. UI/UX 화면 구성 명세

### 3.1 공통 좌측 사이드바 (ChatGPT / Claude 스타일)
* **공통 유지**: 홈 화면(`/`)과 상세 페이지(`/trips/[tripId]`) 어디에서든 좌측에 고정 유지되어, 언제든 홈으로 나가거나 다른 여행 방으로 즉시 이동 가능.
* **상단**: WanderMap 심볼 로고 + `+ 새 여행 계획하기` 버튼.
* **중앙 (무한 스크롤)**: 내가 생성하거나 참여한 여행 방 목록만 독립적으로 스크롤되는 감성 리스트.
* **하단 고정**: 사용자 닉네임 + `이메일 미인증` 뱃지 + 마이페이지/설정 탭 + 로그아웃.

### 3.2 메인 홈 화면 (대화형 허브)
* **상단 감성 가이드 대형 타이포 문구**:
  - *"설렌 마음 그대로 계획해볼까요?"*
  - *"어디로 떠나나요, {nickname}님?"*
  - *"WanderMap과 함께 그리는 우리만의 지도"*
* **중앙 퀵 칩**: 목적지(도시/지역) 및 일정 선택 칩 (선택 사항).
* **중앙-하단 대형 AI 프롬프트 바 (핵심 킥!)**:
  - ChatGPT/Gemini 스타일의 라운드형 대형 입력창.
  - 전송 시 감성적인 회전 로딩 애니메이션 실행.
  - 결과 생성 완료 시 부드러운 페이드 전환과 함께 **동선 상세 페이지로 자동 이동**.

### 3.3 여행 동선 상세 페이지 (3단 워크스페이스)
* **좌측**: 공통 사이드바 유지.
* **중앙 (지도 뷰)**:
  - 네이버/구글 지도 API 기반 인터랙티브 맵.
  - Day 1, Day 2 일자별 탭 필터 및 핀 번호(1, 2, 3...) 마커 + 동선 Polyline(연결선) 시각화.
* **우측 상단 (참여 멤버 관리 박스)**:
  - **초대 링크 복사**: 원클릭 클립보드 복사 및 토스트.
  - **회원**: 프로필 사진, 닉네임, 방장 뱃지(👑).
  - **게스트(Guest)**: 초대 링크로 비로그인 입장 시 기본 아바타 + `관람 모드(Guest)` 뱃지 + **동선 수정/투표 권한 비활성화(조회 전용)**.
* **우측 하단 (일자별 동선 타임라인)**:
  - 카테고리 태그(맛집, 카페, 관광지, 숙소)와 이동 시간, 메모 카드.
  - 장소 직접 추가, 순서 드래그/이동, 삭제 지원.
* **상세 내 Gemini식 중앙 확장 프롬프트 바**:
  - 상세 페이지 하단/우측의 `AI 동선 추천` 버튼 클릭 시 **화면 중앙으로 부드럽게 확장되는 입력 폼**.
  - 세부 요구사항("2일차 오후에 나라 사슴공원 대신 교토 청수사 코스로 변경해줘") 입력 후 재추천.
